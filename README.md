## What Is EditSpark?

EditSpark brings photo and PDF editing into a single web interface. Because it runs through the browser, it provides a lightweight way to work with images and documents without moving between separate applications.

The application is structured around Python, Flask, and HTML. Its uncomplicated web architecture supports local operation, self-hosted installations, and repository-based workflows where editing tools need to be available through a browser.

## Getting Started

Obtain the repository by cloning it or download the source files, then run the application from the Python environment you intend to use.

    git clone https://github.com/will-hallmvrq9252/editspark-web-editing-hub.git
    cd editspark
    python app.py

Install the required dependencies before launching the application. If your copy uses another filename for the primary entry point, run that file instead.

## Using the Editor

1. Start the server and visit the application in a browser.
2. Select a photo or PDF editing task.
3. Use the actions provided by the interface to make your changes.
4. Save or export the resulting file.

When running EditSpark yourself, leave the project active on the machine hosting it and open the local or hosted address displayed in the terminal.
